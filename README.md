# Sundhamata Mobile

Customer app and store admin panel for Sundhamata Mobile: purchases, invoices and loyalty points.

| Folder | What | Stack |
|---|---|---|
| `frontend/` | Customer app (`/`) and admin panel (`/admin`) in one Vite app | React 19, React Router, Tailwind |
| `backend/` | REST API | Node.js, Express 5, MongoDB/Mongoose |
| `docs/API.md` | API reference, business rules, local setup | |

## Run locally

```bash
# API — http://localhost:5000
cd backend
npm install
cp .env.example .env     # set MONGODB_URI and JWT_SECRET
npm run seed             # development data (refuses to run in production)
npm run dev

# Apps — http://localhost:5173 (customer) and http://localhost:5173/admin
cd frontend
npm install
cp .env.example .env     # VITE_API_URL=http://localhost:5000/api/v1
npm run dev
```

Tests: `cd backend && npm test`. See [docs/API.md](docs/API.md) for details and development logins.

## Deploy

### Backend → Render

Render → **New → Blueprint** → this repository (uses `render.yaml`), then set:

| Variable | Value |
|---|---|
| `MONGODB_URI` | Atlas connection string, database `sundhamata` |
| `CUSTOMER_FRONTEND_URL`, `ADMIN_FRONTEND_URL` | The Vercel URL, e.g. `https://sundhamata.vercel.app` |

`JWT_SECRET` is generated by Render. In MongoDB Atlas → Network Access, allow Render's outbound IPs (or `0.0.0.0/0`).
Check `https://<service>.onrender.com/api/v1/health`.

### Frontend → Vercel

Import the repository and set **Root Directory** to `frontend` (framework: Vite). `frontend/vercel.json` rewrites all routes to `index.html`, so deep links such as `/admin/customers/…` work on refresh.

| Variable | Value |
|---|---|
| `VITE_API_URL` | `https://<service>.onrender.com/api/v1` |

`VITE_API_URL` is read at build time — redeploy after changing it.

### Before going live

- Customer login needs an SMS provider: with `NODE_ENV=production` the fixed development OTP is disabled and the built-in `console` provider refuses to send. Add a provider in `backend/src/services/sms/index.js`.
- Replace the seeded development admin password (`Admin@123`) in any database that faces the internet.
